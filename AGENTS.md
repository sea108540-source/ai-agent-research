# AGENTS.md

## Mission
Create a weekly research brief about AI agents in general. Codex is a tool used to run the research workflow, but the research subject is broader than Codex itself.

## Research scope
Cover AI agents broadly, including:
- agent design
- orchestration
- tool use
- MCP
- workflows and automations
- evaluation and benchmarking
- safety and reliability
- real-world use cases
- useful supporting tools such as Codex when relevant

## Source policy
Search broadly across public sources when available and useful:
1. official documentation
2. official changelogs and release notes
3. official blogs and announcements
4. research papers
5. repositories and technical discussions
6. developer forums
7. credible news coverage
8. social platforms such as X when they add signal

Prefer primary sources. Use social sources to spot signals, not as the sole basis for major claims when better sources exist.

## Output requirements
For each weekly run, create:
- `reports/YYYY/YYYY-MM-DD/summary.md`
- `reports/YYYY/YYYY-MM-DD/signals.json`
- `reports/latest/summary.md`
- `reports/latest/signals.json`
- update `reports/index.md`

## Quality bar
For each important topic, explain:
- what changed
- why it matters
- learning value
- work-efficiency value
- development or PoC value
- confidence level
- source list

## Prioritization
When ranking topics, prefer in this order:
1. practical usefulness
2. development usefulness
3. learning value
4. novelty
5. urgency

## Guardrails
- Separate facts from interpretation.
- Flag uncertainty explicitly.
- Avoid filler and duplicates.
- Limit the main report to the most important items.
- Make recommendations concrete.
